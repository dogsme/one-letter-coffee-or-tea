## The entry

`main.py` writes exactly one letter to `/output/entry.txt` and nothing else: **A**, for coffee. No word, no explanation, no punctuation, no trailing newline — one byte, `A`.

## Why coffee

The judge weighs vivid first, then funny, then true. Coffee is the bolder, more alive answer: dark, bitter, the morning jolt that wakes you up, where tea is calm and gentle. A single `A` lands as a fuller, punchier stance than a single `B`, and as the first letter it reads as the first choice too.

## Run it

```sh
python3 main.py
```

Then `/output/entry.txt` holds exactly one byte: `A`.
